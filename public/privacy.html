Kebijakan Privasi & Ketentuan

Terakhir diperbarui: 2026-10-12

1. Data lokal

Proyek, audio, dan pengaturan Anda disimpan di IndexedDB browser pada perangkat Anda sendiri. MooScript Studio tidak memiliki server aplikasi, akun pengguna, analitik, maupun cookie pelacak.

2. API key

API key disimpan di IndexedDB perangkat (mode “Persisten”) atau di sessionStorage (mode “Sesi”; terhapus saat tab ditutup). Key tidak pernah dikirim ke server MooScript; key hanya dikirim langsung dari browser Anda ke provider yang Anda pilih. Mode Persisten menyimpan key sebagai teks biasa di perangkat, jadi hindari memakainya di komputer bersama.

3. Permintaan jaringan

Aplikasi hanya dapat menghubungi alamat berikut (dibatasi oleh Content Security Policy):

  • generativelanguage.googleapis.com (Google Gemini)
  • api.openai.com (OpenAI)
  • api.groq.com (Groq)
  • api.anthropic.com (Anthropic)
  • openrouter.ai (OpenRouter)
  • api.elevenlabs.io (ElevenLabs)
  • huggingface.co dan xethub.hf.co (hanya saat mengunduh model suara lokal)

Permintaan ke provider AI hanya terjadi bila Anda memakai fitur terkait, dan tunduk pada kebijakan privasi provider tersebut.

4. Penghapusan data

Hapus data lewat fitur “Clear site data” di browser, atau lewat tombol hapus proyek dan hapus cache audio di Pengaturan. Browser tertentu (misalnya Safari) dapat menghapus data situs secara otomatis; gunakan fitur Unduh Cadangan di Manajer Proyek untuk menyimpan salinan.

5. Ketentuan penggunaan

  • MooScript Studio dilisensikan di bawah GNU Affero General Public License v3.0 atau yang lebih baru (AGPL-3.0-or-later). Kode sumbernya tersedia di github.com/hernataramadhan79-bit/MooScript.
  • Perangkat lunak disediakan apa adanya, tanpa jaminan apa pun.
  • Anda bertanggung jawab atas biaya pemakaian API provider yang Anda gunakan.
  • Anda wajib mematuhi ketentuan layanan masing-masing provider AI.
  • Anda bertanggung jawab atas konten yang Anda hasilkan dan publikasikan.
